# AI Startup Scout 商业化行动手册

> 定位：**AI创业项目的智能分析师——不只是搜索，而是帮你分析值不值得关注**
> 目标：3个月内从0用户做到500用户，验证付费意愿
> 制作时间：2026年6月11日

---

## 一、整体路线图

```
第1-2周  ──→ MVP验证期：日报系统 + 商店优化 + 反馈入口
第3-4周  ──→ 种子用户期：社区渗透 + 内容引流 + 10人深度访谈
第5-8周  ──→ 产品迭代期：功能加固 + 付费体系搭建 + 用户增长机制
第9-12周 ──→ 变现验证期：付费上线 + 转化优化 + 规模化方向判断
```

**核心原则：每一步都要产生可观测的数据，用数据驱动下一步决策。**

## 二、第1-2周：MVP验证期

### 2.1 搭建"AI创业融资日报"邮件系统

**为什么先做这个：**
- 不改产品代码，利用现有插件的搜索+AI分析能力
- 邮件是最低摩擦的获客渠道——用户不需要安装任何东西
- 日报本身就是内容营销，展示产品价值

**具体开发任务：**

| # | 任务 | 技术方案 | 预计耗时 | 交付物 |

## 四、第5-8周：产品迭代期

### 4.1 功能迭代（基于用户反馈优先级排序）

**高优先级（必须做）：**

| # | 功能 | 为什么 | 技术方案 | 预计耗时 |
|---|------|-------|---------|---------|
| 1 | 用户账号体系 | 没有账号就无法付费、无法跨设备同步 | Chrome Identity API（Google登录，最轻量） | 3天 |
| 2 | 搜索历史 | 用户回来能继续，增加留存 | 云端存储（用你的Vercel后端） | 2天 |
| 3 | AI分析增强 | 这是核心差异化，要做得更好 | 支持多轮追问、对比分析、导出报告 | 5天 |

**中优先级（看反馈决定）：**

| # | 功能 | 为什么 | 预计耗时 |
|---|------|-------|---------|
| 4 | 每日推送通知 | 主动触达，提高DAU | 2天 |
| 5 | 项目关注/监控 | 跟踪特定项目的动态变化 | 3天 |
| 6 | 分享分析结果 | 口碑传播 | 1天 |

**低优先级（暂时不做）：**

| 功能 | 为什么不做 |
|------|---------|
| 项目数据库 | 工程量太大，等有用户数据再说 |
| 技术真实性验证 | 需要跑demo，基础设施成本高 |
| 团队协作 | 早期没有B端客户 |

### 4.2 付费体系搭建

**免费/付费划分方案：**

| 功能 | 免费版 | 付费版（¥29/月 或 $4.9/月） |
|------|--------|--------------------------|
| 搜索次数 | 每天5次 | 无限 |
| AI分析 | 每天1次 | 无限 + 支持多轮追问 |
| 搜索结果 | 每次最多5条 | 每次最多20条 |
| 收藏数量 | 最多20个 | 无限 |
| 日报邮件 | ❌ | ✅ 每日推送 |
| 报告导出 | ❌ | ✅ PDF/Markdown |
| 项目监控 | ❌ | ✅ 最多10个 |

**为什么这么划：**
- 搜索和AI分析是最高频功能，限制次数能驱动付费
- 日报邮件是"付费才有的服务"，不是功能限制，心理接受度高
- ¥29/月在信息工具里属于低门槛（对比：Crunchbase $49/月，PitchBook企业级）

**技术实现路径：**

```
1. 用Google登录获取用户身份（Chrome Identity API）
2. 后端维护用户表（免费/付费状态+用量计数）
3. 每次搜索/分析前检查用量
4. 付费接入：
   - 方案A：Stripe（国际用户）+ 微信/支付宝（国内用户）
   - 方案B：LemonSqueezy（更轻量，支持全球支付）
   - 推荐：先用LemonSqueezy，最快上线
```

**付费转化漏斗设计：**
```
安装插件 → 首次搜索（免费体验价值）
         → 第3次搜索（开始习惯）
         → 触达免费上限（"今日搜索次数已用完，升级获取无限搜索"）
         → 付费页（展示付费版完整能力）
         → 支付
```

### 5.3 规模化方向判断

**第12周末，根据数据做决策：**

| 数据表现 | 决策 |
|---------|------|
| 付费转化率 >5%，月收入 >¥1000 | 继续深耕，考虑做独立网站扩大入口 |
| 付费转化率 2-5%，有忠实用户 | 优化转化漏斗，调整定价，再观察1个月 |
| 付费转化率 <2%，但DAU高 | 用户喜欢但不付费，考虑广告模式或数据变现 |
| DAU低，付费意愿低 | 转型：换切入点或做to-B方向（咨询报告） |
